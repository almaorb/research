# memory

What this project has learned: decisions, preferences and corrections that
every contributor and every coding agent must follow. One topic per file,
plain Markdown, committed with the code.

Project memory lives here, in the repository, never in hidden dot-folders
(`.claude/`, `.cursor/`, a tool's own memory store). A lesson that is not in
this folder is not part of the project.

When you learn something durable about how this project is built, add a file
here (or edit the one it belongs to) in the same commit as the change.
